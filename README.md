# 수댕로그 사용설명서

운동·식단·물·영양제·인바디를 하루 단위로 기록하는 개인용 앱이다.
아이폰 사파리로 열어 홈 화면에 추가하면 앱처럼 쓸 수 있고, 기록은 전부 폰 안에만 저장된다.

---

## 시작하기

### 홈 화면에 앱으로 추가

1. 사파리로 앱 주소를 연다 (`https://아이디.github.io/저장소이름/`)
2. 하단 공유 버튼 → **홈 화면에 추가**
3. 생긴 아이콘으로 들어간다

이때부터 **반드시 홈 화면 아이콘으로 들어가서 기록해야 한다.** 사파리 탭에서 여는 것과
홈 화면 앱은 저장 공간이 서로 분리되어 있어서, 사파리에서 넣은 기록은 홈 화면 앱에서
보이지 않는다.

### 파일 구성

저장소에 올려야 하는 파일은 두 개다.

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (화면·기능이 전부 이 안에 있다) |
| `sw.js` | 오프라인 지원. 없어도 앱은 돌아가지만 인터넷이 있어야 열린다 |

`fitlog-backup.json`은 기록 복원용이라 **저장소에 올리면 안 된다.** 개인 인바디 수치가
들어 있고 저장소는 공개이기 때문이다.

---

## 화면 구성

상단에 탭 세 개와 데이터 버튼이 있다.

| 탭 | 내용 |
|---|---|
| **달력** | 월간 달력. 날짜를 눌러 그날 기록을 넣는다 |
| **운동 도감** | 운동 목록, 자세·동작 이미지, 선생님 루틴 |
| **인바디** | 체성분 측정 기록과 변화 추이 |
| **⇅** | 데이터 백업 내보내기 / 복원 |

헤더 오른쪽에는 이번 주 운동 횟수와 물 평균이 항상 떠 있다.

## 달력

### 점의 의미

날짜 칸 아래 점으로 그날 무엇을 기록했는지 보여준다.

| 점 | 뜻 |
|---|---|
| 주황 | 개인운동 |
| 보라 | PT |
| 노랑 | 식단 |
| 갈색 | 단백질 |
| 청록 | 물 |
| 분홍 | 영양제 |
| 파랑 | 인바디 |

운동 점은 **실제 내용이 있을 때만** 생긴다. 개인운동·PT 버튼만 눌러두고 시간·운동·메모를
하나도 안 넣었으면 점이 안 생기고, "이번 주 운동 N회"에도 포함되지 않는다.

칸이 좁아서 점은 최대 3개(폰처럼 좁은 화면에서는 2개)까지만 찍히고, 나머지는 `+2`처럼
숫자로 줄여서 보여준다. 그날 무엇을 기록했는지는 날짜를 눌러서 확인하면 된다.

운동 시간을 넣으면 날짜 칸에 `50분`처럼 표시된다.

### 이동

`오늘` 버튼으로 이번 달로 돌아오고, `‹` `›`로 달을 넘긴다.

## 하루 기록

날짜를 누르면 그날 기록 창이 열린다.

### 저장 방식 (중요)

날짜를 열면 **편집용 사본**이 만들어진다. 무엇을 고치든 오른쪽 위 **저장**을 눌러야
실제로 반영된다.

- 저장 전에는 달력에 아무 변화도 생기지 않는다
- 바꾼 게 있으면 저장 버튼이 주황색으로 켜지고 제목 아래 "저장 안 된 변경사항"이 뜬다
- 그 상태로 닫으려 하면 **저장하고 닫기 / 그냥 닫기**를 물어본다

### 요약 보기와 편집

운동과 식단은 **저장하고 나면 요약만 보여준다.** 입력칸이 화면을 다 잡아먹지 않게
하기 위해서다. 요약은 이렇게 나온다.

```
PT  60분
로우 (빨간 머신)
  1세트   15회 × 10kg   실패 · 마지막 2회 실패
  2세트   12회 × 12.5kg
점심  12:30  샐러드
```

고치고 싶으면 구역 오른쪽 위 **편집**을 누른다. 입력칸이 다시 펼쳐지고,
**접기**를 누르거나 **저장**하면 다시 요약으로 돌아간다.
아직 아무것도 안 적은 구역은 처음부터 입력칸이 펼쳐져 있다.

### 운동

**안 함 / 개인운동 / PT** 중에서 고른다. 이미 선택된 것을 다시 누르면 해제된다.

운동 시간(분)을 넣고, **+ 운동 선택하기**로 그날 한 운동을 고른다.

운동을 고르면 운동마다 카드가 하나씩 생기고, 카드 안에서 이런 걸 기록한다.

- **내 방식대로 / 선생님 운동법** — 이 운동을 어떤 방식으로 했는지
- **웜업 세트** — `+ 웜업 세트 추가`
- **본 세트** — 세트마다 횟수(회)와 무게(kg)
- **세트 실패** — 세트 줄의 `✕`를 누르면 실패로 표시되고, 왜 못 했는지 적는 칸이 열린다
- **운동 중 메모** — 뭐가 잘 됐고 뭐가 힘들었는지

카드에서 운동 이름을 누르면 그 운동의 상세(자세·동작 이미지)가 열린다.

'선생님 운동법'을 고르면 카드 안에 선생님이 지정한 무게·횟수가 같이 뜨고,
**이대로 세트 채우기**를 누르면 그 세트가 그대로 입력된다.

### 식단

아침·점심·저녁은 각각 **시간**과 **먹은 것**을 적는다. 간식은 `+ 간식 추가`로
여러 번 넣을 수 있고, 간식도 각각 시간이 있다. 각 간식 오른쪽 `✕`로 지운다.

### 영양제

종합비타민·비타민C·비타민D·오메가3·마그네슘·크레아틴·간 영양제·유산균·아연·콜라겐·철분·
프로틴이 기본으로 있다. 눌러서 켜고 끈다.

목록에 없으면 **기타 (직접 입력)**으로 추가하면 그때부터 계속 목록에 남는다.

**순서 바꾸기** — 칩을 꾹 눌러서 끌면 순서가 바뀌고 그대로 저장된다.
살짝 누르는 건 켜기/끄기라서 서로 겹치지 않는다.

### 단백질

`+1g` `+5g` `+10g` `+20g` 버튼을 누를 때마다 더해진다. 프로틴 쉐이크나 단백질 바처럼
따로 챙겨 먹은 양을 적는 칸이다. `초기화`로 그날 값을 0으로 되돌린다.

### 물

`+100ml` `+250ml` `+500ml` 버튼을 누를 때마다 더해진다. 목표 2L 대비 진행률이 막대로
보이고, `초기화`로 그날 물을 0으로 되돌린다.

### 인바디

그날 측정 기록이 있으면 요약이 보인다. **인바디 탭에서 추가하기 →** 또는
**CSV로 가져오기**로 넘어갈 수 있다.

## 운동 도감

등록된 운동을 부위별로 본다. 위쪽 검색창으로 이름·자극 부위를 검색하고,
부위 칩(전체·가슴·등·어깨·팔·하체·코어·유산소)으로 걸러 본다.

### 목록에서 보이는 것

- 동작 이미지 썸네일
- 운동 이름 / 장비 · 자극 부위
- **쌤 N** — 선생님 운동법이 등록된 운동
- **기록** — 한 번이라도 기록한 적 있는 운동
- **★ / ☆** — 즐겨찾기

### 즐겨찾기

별을 누르면 맨 위 **★ 내가 자주 하는 운동**에 모인다. 자유롭게 넣고 뺄 수 있다.
운동 선택 화면에서도 즐겨찾기가 맨 위에 나온다.

### 선생님 루틴 (도감에서 바로)

도감 위쪽 **선생님 루틴** 버튼을 누르면 등록해둔 루틴 목록이 뜨고, 맨 위 
**+ 선생님 루틴 붙여넣기**로 새로 등록한다. 날짜를 먼저 열지 않아도 된다 — 여기서
루틴을 적용하면 달력의 오늘 날짜가 자동으로 열리면서 운동이 채워진다.

### 내 운동 추가

목록에 없는 운동은 **+ 내 운동 추가**로 직접 만든다. 이름·부위·장비·자극 부위·준비 자세·
수행 방법·각도 유의사항을 넣으면 도감에 그대로 들어간다. 운동 선택 화면에서도 추가할 수 있다.

## 운동 상세

운동을 누르면 열리고, 탭이 두 개다.

### 기본 운동법

- 동작 이미지 (GIF)
- 부위 · 장비 태그, 자극 부위
- 즐겨찾기 버튼
- **① 준비 자세 잡는 법**
- **② 운동 수행 방법**
- **③ 각도 · 자세 유의사항**
- **④ 실제 시범 영상 · 이미지** — 원본 사이트와 유튜브 검색 링크

이미지 아래 칸에 원하는 GIF·이미지 주소를 넣고 **적용**을 누르면 그 운동에 계속 그
이미지가 쓰인다. **기본값** 버튼으로 되돌린다. 이미지가 없거나 안 불러와지는 운동은
여기서 직접 채우면 된다.

### 선생님 추천

선생님이 알려준 운동법을 이 운동에 대해 **날짜별로 여러 장** 쌓아둔다. 가장 최근 것이
기본으로 뜨고, 위쪽 목록에서 다른 날짜를 골라 볼 수 있다.

받은 내용을 그대로 붙여넣으면 **무게 · 횟수 · 세트로 나눠서** 정리된다.
저장 전에 어떻게 정리될지 미리 보여준다.

- **이대로 운동 기록에 넣기** — 오늘 기록에 이 운동과 세트를 채운다
- **수정 / 삭제**

## 선생님 루틴

선생님이 카톡으로 보내주는 루틴 전체를 통째로 등록하는 기능이다.
개별 운동이 아니라 **루틴 묶음** 단위로 다룬다.

### 들어가는 곳 두 군데

| 어디서 | 경로 |
|---|---|
| 운동 도감 | **선생님 루틴** 버튼 |
| 하루 기록 | 날짜 → **+ 운동 선택하기** → 위쪽 **선생님 루틴** 탭 |

둘 다 같은 목록을 본다. 어디서 등록하든 양쪽에 다 나온다.

### 등록

루틴 목록 맨 위 **+ 선생님 루틴 붙여넣기**를 누르고, 받은 원문을 그대로 붙여넣는다.

**여러 루틴을 한 번에 붙여넣어도 된다.** 상체 루틴과 하체 루틴을 이어서 붙여넣으면
루틴 두 개로 나눠서 각각 저장된다. `개인운동 상체 루틴`, `하체 개인운동`처럼
'루틴'이나 '운동'이 들어간 줄을 새 루틴의 시작으로 본다.

### 읽어내는 형식

선생님이 쓰는 방식이 두 가지인데 둘 다 읽는다. 루틴마다 형식을 먼저 판별하기 때문에
한 번에 붙여넣어도 섞이지 않는다.

**형식 1 — 운동 이름은 그냥 한 줄, 설명은 번호**

```
개인운동 상체 루틴          ← 루틴 이름

빨간색 인클라인 프레스        ← 운동 이름 (표시 없음)
1. 손잡이 기준 좌석은 겨드랑이 바로 아래   ← 준비/수행 설명
2. 손잡이 제일 안쪽을 잡고
- 2.5kg x 15번             ← 세트
- 빈봉 x 12번               ← '빈봉'도 인식
```

**형식 2 — 운동 이름에 번호, 설명도 `-`**

```
하체 개인운동                ← 루틴 이름

1. 5분 정도 가벼운 유산소로 몸에 열 내주기   ← 루틴 전체 메모

2. 아웃타이(힙 어브덕션)      ← 운동 이름 (번호)
- 발판에 뒷꿈치를 다 넣어놓고  ← 설명
- 40kg x 20번               ← 세트
```

- `-`가 없어도 세트로 인식한다 (`빈봉 x 20번`처럼 그냥 적어도 된다)
- 횟수가 없는 줄은 세트가 아니라 메모로 남는다 (`무게는 33kg 고정`)
- 메모에 무게와 횟수와 세트 수가 흩어져 있어도 합쳐서 세트로 만든다
  (`무게는 33kg 고정` + `각 그립마다 15개씩 … 총 5세트` → 33kg 15회 5세트)
- 운동 이름은 도감의 운동에 자동으로 연결된다 (`빨간색 로우` → `로우 (빨간 머신)`)
- 괄호가 있어도 찾아낸다 (`아웃타이(힙 어브덕션)` → `힙 어브덕션 머신`)
- 운동 시작 전 안내는 루틴 전체 메모로 따로 남는다

### 사용

루틴 목록에서 하나를 누르면 상세가 열린다. 운동마다 세트 요약과 선생님 설명이 보이고,
자동 연결이 틀렸거나 못 찾았으면 드롭다운으로 직접 고를 수 있다.

**이 루틴으로 오늘 기록 채우기** 한 번이면 루틴에 들어 있는 운동들이 세트까지 그대로
그날 기록에 들어간다. (그 뒤에 저장을 눌러야 반영된다.)

도감에서 눌렀다면 달력의 오늘 날짜가 자동으로 열리면서 채워지고,
하루 기록에서 눌렀다면 열어둔 그 날짜에 채워진다.

## 인바디

### 요약 카드

가장 최근 측정의 체중·골격근량·체지방률·체수분·기초대사량·인바디점수·내장지방레벨과
이전 측정 대비 증감을 보여준다.

### 추이 차트

체중 · 골격근량 · 체지방률 · 체수분 네 가지의 변화 추이.

### 측정 기록

날짜별 표. 날짜·체중·골격근량·체지방량·체지방률·BMI·체수분·기초대사·내장지방·점수가
보이고, **행을 누르면 그 날짜의 전체 항목 상세**가 열린다.

상세에서는 항목이 그룹별로 나뉘어 나오고 이전 측정 대비 증감이 함께 표시된다.

| 그룹 | 항목 |
|---|---|
| 기본 체성분 | 체중, BMI, 기초대사량, 인바디 점수 |
| 골격근 · 지방 | 골격근량, 근육량, 체지방량, 체지방률, 내장지방레벨, 내장지방단면적, 복부지방률, 허리둘레, SMI |
| 체수분 | 체수분, 세포내수분, 세포외수분, 세포외수분비 |
| 영양 · 균형 | 단백질, 무기질, 골무기질량, 체세포량, 전신 위상각, 다리 근육량·레벨, 상체·하체 / 좌·우 균형 |
| 부위별 상세 | 팔·다리·몸통의 근육량, 체지방, 세포외수분비 |

상세에서 바로 **항목 수정하기 / 삭제**할 수 있다.

### 직접 입력

**+ 기록 추가**로 한 건씩 넣는다. 자주 쓰는 항목이 먼저 나오고,
"부위별 · 상세 항목 더보기"를 펼치면 나머지 전부를 넣을 수 있다.

### CSV 가져오기

**CSV 가져오기**로 인바디 기기·앱에서 내보낸 파일을 그대로 넣는다.
파일 선택도 되고 내용을 붙여넣어도 된다.

- 열 이름을 알아서 항목에 맞춘다 (`체중(kg)`, `체수분(L)`, `내장지방레벨(Level)` 등)
- 날짜가 `20260905130838` 같은 형식이어도 읽는다
- 측정 안 된 항목(`-`)은 건너뛴다
- 알아보지 못한 열은 메모로 남긴다

`미리보기`로 몇 건이 인식됐는지 먼저 확인한 뒤 가져온다.

## 데이터 · 백업 (⇅)

기록은 **이 폰의 이 앱 안에만** 저장된다. 서버로 가지 않는다.

- **백업 파일 내보내기** — 전체 기록을 JSON 파일 하나로 받는다
- **백업 복원** — 파일을 고르거나 내용을 붙여넣고
  **지금 기록에 합치기** 또는 **전부 덮어쓰기**

현재 저장된 일수와 용량, 마지막 저장 시각도 여기에서 보인다.

### 백업이 필요한 이유

홈 화면 앱은 오래 안 열어도 데이터가 지워지지 않는다(애플이 홈 화면 웹 앱은
7일 삭제 규칙에서 제외한다고 명시해 두었다). 하지만 이런 경우엔 사라진다.

- 홈 화면 아이콘을 삭제할 때
- 폰을 초기화하거나 잃어버렸을 때
- 새 폰으로 바꿀 때 (iCloud로 동기화되지 않는다)

한 달에 한 번쯤 백업 파일을 받아서 카톡 나에게 보내기나 iCloud에 두면 충분하다.

## 알아둘 점

**동작 이미지는 fitnessprogramer.com에서 직접 불러온다.** 파일을 복사해 온 게 아니라
그 사이트 주소를 그대로 참조하는 방식이라 출처와 원본 링크가 함께 표시된다.
원본이 옮겨지거나 막히면 "이미지를 불러오지 못했어요"가 뜨는데, 그때는 운동 상세 ④에서
다른 주소를 넣으면 된다.

**클로드 안에서 열리는 버전에서는 GIF가 안 보인다.** 보안 정책상 외부 이미지를
불러올 수 없기 때문이다. 대신 그쪽은 기록이 서버에 저장돼서 기기가 바뀌어도 유지된다.
사파리 홈 화면 앱과 클로드 안의 버전은 **저장 공간이 완전히 별개**이므로, 하나를
본체로 정해서 쓰는 게 좋다.

**주소를 아는 다른 사람이 열어도 기록은 섞이지 않는다.** 각자 자기 폰에만 저장되고,
데이터를 주고받는 통로가 애초에 없다.
